# Testing_LLM

## Setup

Create a virtual environment:

python -m venv .venv

Activate it:

.venv\Scripts\activate

Install dependencies:

pip install -r requirements.txt

Create a .env file from .env.example.

Run:

python -m evaluation.run_experiment
